Chief Reef

Can score corals all levels, algaes net and processor, human player station corals intake, reef algae intake, deep climb.

![image](https://github.com/user-attachments/assets/3f050bf7-c5f6-4993-aace-ab001db732c6)


Controller(PS5) layout for 2 drivers mode:

  Driver controller:

    L3 - lock the wheels
    R3 - vision(rotation towards the reef)
    PS - reset the gyro
    L1, R1 - drive to the middle of the reef
    L2 - drive to the left of the reef
    R2 - drive to the right of the reef
    options - open ramp and get climber out
    create - climb

  Operator controller:

    L2 - home position, intaking coral
    touchpad - home position with algae
    R2 - run endeffector forward(score)
    R1 - run endeffector backwards(suck in)
    povUp - net position
    povDown - processor position
    povLeft - algae L2 position(remove)
    povRight - algae L3 position(remove)
    cross - L1 coral position
    triangle - L4 coral position
    circle - L3 coral position
    square - L2 coral position
    button(15) - switch from samrt to manual mode
